# तिघरा–गंगेरुआ–बरघाटी–बालाघाटी पवारी शब्दकोश

यह शब्दकोश तिघरा–गंगेरुआ–बरघाटी–बालाघाटी पवारी भाषा के
शब्दों, वाक्यों, व्याकरण और कहावतों का संग्रह है।

## शब्दावली

| हिंदी | पवारी | English |
|---|---|---|
| क्या | काजक | What |
| नहीं | नइ | No |
| हाँ | हव | Yes |
| खाना | जेवन | Eat |
| विवाह | बीहा | Marriage |
| सोना | सोवन | Sleep |

## उदाहरण

**हिंदी:** वह लड़की भाग जाएगी।  
**पवारी:** वा टूरी पराय जाहे।

**हिंदी:** वह लड़का स्कूल नहीं जाता है।  
**पवारी:** यो टूरा स्कूल नई जाय।

## कहावतें

### नहान जिया, पातर सिया
अर्थ: कंजूस व्यक्ति खाने की थाली नहीं खरीद सकता,
वह खाने के लिए पत्तल सिलता है।
